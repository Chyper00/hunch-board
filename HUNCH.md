# Hunch Board

This folder has a `board.hunch`: the plan of this project, as a board anyone can edit. A box can hold a board of its own, in `boards/`. Files on it live in `assets/`.

- Read `.claude/skills/hunch/SKILL.md` before you change a `.hunch` file.
- Check the drawing: `npx hunch-board check --json`
- The same CLI, with no install: `node .hunch/hunch.mjs check --json`
- Skill, CLI and examples: https://github.com/Chyper00/hunch-board
- The board in the browser: https://www.hunchboard.dev/board
